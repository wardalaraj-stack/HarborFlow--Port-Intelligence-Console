============================================================
STEP 3 - CREATE THE THREE REGEX PATTERNS
============================================================

Add these near the top of text_tools.py:

    CONTAINER_PATTERN = re.compile(
        r"\b[A-Za-z]{4}\d{7}\b",
        re.IGNORECASE,
    )

    SEAL_PATTERN = re.compile(
        r"\bSEAL-\d{6}\b",
        re.IGNORECASE,
    )

    EMAIL_PATTERN = re.compile(
        r"[A-Za-z0-9._%+\-]+@[A-Za-z0-9.\-]+\.[A-Za-z]{2,}"
    )

What each pattern means:

    Container:
        exactly four letters and seven digits
        example: MSCU1234567

    Seal:
        SEAL- followed by exactly six digits
        example: SEAL-884210

    Email:
        allowed text before @, a domain, and a final . plus at least
        two letters
        example: ops@harborflow.se

re.IGNORECASE means these also match:

    mscu1234567
    seal-884210

The \b boundaries stop a bigger word or longer number from being partly
redacted by mistake.

============================================================
STEP 4 - CREATE THE PURE SANITIZING FUNCTION
============================================================

Still in:

    code/text_tools.py

Add:

    def sanitize_report(report):
        result = report

        result = re.sub(
            CONTAINER_PATTERN,
            "[CONTAINER]",
            result,
        )
        result = re.sub(
            SEAL_PATTERN,
            "[SEAL]",
            result,
        )
        result = re.sub(
            EMAIL_PATTERN,
            "[EMAIL]",
            result,
        )

        changed = result != report
        return result, changed

This is called a pure function because:

    - it receives text;
    - it returns text and a True/False value;
    - it does not print;
    - it does not ask for input;
    - it does not write a file.

Example:

    original = (
        "Container MSCU1234567 arrived with seal SEAL-884210. "
        "Notify ops@harborflow.se."
    )

    cleaned, changed = sanitize_report(original)

The result should be:

    [CONTAINER] arrived with seal [SEAL]. Notify [EMAIL].

The variable changed should be True.

============================================================
STEP 5 - SORT INCIDENTS BY TITLE
============================================================

Add this helper in text_tools.py:

    def sort_incidents(incidents):
        return sorted(
            incidents.values(),
            key=lambda incident: incident["title"].casefold(),
        )

Why use incidents.values()?

    load_incidents() returns a dictionary.
    .values() gives the incident dictionaries inside it.

Why use casefold()?

    It compares titles without caring about upper- or lowercase letters.

Example sorted list:

    1. Gate congestion delay
    2. Reefer temperature deviation
    3. Reefer transfer delayed
    4. Routine inspection completed

============================================================
STEP 6 - WRITE A CHANGED REPORT
============================================================

Add this helper in text_tools.py:

    def write_sanitized_report(incident_id, sanitized_text, output_dir):
        output_dir = Path(output_dir)
        output_dir.mkdir(parents=True, exist_ok=True)

        output_path = output_dir / f"{incident_id}-sanitized.txt"

        with output_path.open(
            "w",
            encoding="utf-8",
            newline="",
        ) as file:
            file.write(sanitized_text)

        return output_path

Important:

    Do not call this function when changed is False.

This means no output folder or output file is created for a report without
container IDs, seals, or email addresses.

The required output path is:

    exports/sanitized/<incident_id>-sanitized.txt

Example:

    exports/sanitized/INC-102-sanitized.txt
